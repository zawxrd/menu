# 🍱 週一至週五點餐系統

> 一個極簡、無伺服器後端（Serverless）的便當點餐網頁系統，專為 **GitHub Pages** 設計。

## ✨ 系統特色

### 📱 用戶端（點餐）

| 功能 | 說明 |
|------|------|
| 🎯 **簡易操作** | 只需選擇「座號（純數字）」與「餐點」，一鍵送出 |
| 🔒 **隱私保護** | 用戶端不會顯示他人點餐內容 |
| ⚠️ **防重複機制** | 同座號當天再次點餐會提示並覆蓋前筆訂單 |
| ⏰ **智能切換** | 自動依截止時間（預設 12:00）切換至隔天或下週一預訂 |

### 🛠️ 維護端（管理）

| 功能 | 說明 |
|------|------|
| 🔐 **密碼保護** | 預設密碼 `admin1234`，可於設定頁面自行變更 |
| 📝 **菜單管理** | 支援手動新增/編輯/刪除，亦可上傳 CSV |
| 📊 **訂單檢視** | 按星期檢視訂單、即時統計餐點份數與總金額 |
| 💾 **匯出功能** | 一鍵匯出各日訂單 CSV，或生成彙總文字供複製發送 |
| 💻 **純前端運作** | 所有訂單與設定均儲存在瀏覽器 `localStorage` 中 |

### 🤖 AI 自動更新工具

| 特性 | 說明 |
|------|------|
| 🔑 **安全調用** | 本機端呼叫 Gemini/Claude API，**API Key 不外洩到前端** |
| 📄 **多格式支援** | 支援 **PDF**、**PNG**、**JPG** 菜單檔案 |
| 🚀 **自動推送** | 解析後自動產出 CSV，並透過 `git push` 推送至 GitHub |

## 🚀 快速開始

### 前置需求

- Python 3.8+
- Git
- Google Gemini API Key（或其他相容的 AI API）

### 一鍵部署

```bash
# 1. 初始化 Git 倉庫
git init

# 2. 提交所有檔案
git add .
git commit -m "feat: initial commit for order system"

# 3. 連結遠端倉庫（替換為你的倉庫網址）
git remote add origin https://github.com/你的帳號/你的倉庫名稱.git

# 4. 推送至 main 分支
git branch -M main
git push -u origin main
```

### 啟用 GitHub Pages

1. 前往 GitHub 倉庫的 **Settings** → **Pages**
2. 在 **Build and deployment** 下選擇：
   - **Branch**: `main`
   - **Folder**: `/ (root)`
3. 點擊 **Save**，等待 1-2 分鐘即會生成專屬網址

## 🤖 每週自動更新菜單

### 第一步：安裝依賴（僅需執行一次）

```bash
pip install google-genai
```

> 💡 **提示**：建議將 API Key 設為環境變數 `GEMINI_API_KEY`，避免每次重複輸入。

### 第二步：更新菜單

1. 雙擊執行 `run_converter.bat`（Windows）或執行 `python menu_to_csv.py`
2. 選擇新一週的菜單檔案（支援 PDF/PNG/JPG）
3. 系統自動完成：
   - ✅ AI 辨識週一至週五餐點與價格
   - ✅ 儲存本機備用 CSV
   - ✅ 更新 `menu.json` 並自動推送至 GitHub
4. **完成！** 所有用戶將自動載入最新菜單

## 📋 CSV 格式規範

若不願使用 AI 工具，可直接在維護端上傳 CSV 檔案：

```csv
星期,餐點名稱,價格
週一,排骨便當,80
週一,雞腿便當,90
週二,魚排便當,75
週三,控肉飯,70
週四,燒肉便當,85
週五,牛丼,95
```

### 格式規則

| 項目 | 說明 |
|------|------|
| **星期欄位** | 支援 `週一～週五`、`1～5`、`Monday～Friday` |
| **標題列** | 第一列會自動識別並略過 |
| **編碼** | 建議使用 UTF-8 編碼 |

## 📧 雲端訂單彙整與自動寄信

透過 **Google 試算表 + Apps Script** 實現：
- ☁️ 雲端訂單自動彙整
- ⏰ 每日中午 12:00 自動寄送統計報表

### 設定流程（約 3 分鐘）

#### 1️⃣ 建立 Google 試算表

1. 開啟 [Google Drive](https://drive.google.com/)
2. 新增 **Google 試算表**，命名為 `辦公室點餐紀錄`
3. 點選 **擴充功能** → **Apps Script**

#### 2️⃣ 部署後端程式碼

1. 複製 `google_sheet_backend.js` 內容，貼上覆蓋 Apps Script 編輯器
2. 修改設定：

```javascript
const CONFIG = {
  ADMIN_EMAIL: "your_email@gmail.com",      // 接收報表的信箱
  SHEET_NAME: "訂單紀錄",
  EMAIL_SUBJECT_PREFIX: "🍱 今日點餐統計回報"
};
```

3. 點擊 **儲存** 💾

#### 3️⃣ 發布為 Web App

1. 點擊 **部署** → **新增部署**
2. 選擇 **網路應用程式**
3. 設定權限：
   - **說明**: `點餐 API`
   - **誰可以存取**: **任何人 (Anyone)** ⚠️ *重要*
4. 點擊 **部署** 並授予權限
5. 複製 **Web App URL**（格式：`https://script.google.com/macros/s/.../exec`）

#### 4️⃣ 綁定到點餐系統

1. 開啟點餐網頁 → **維護端** → **設定**
2. 貼上 Web App URL 至對應欄位
3. **完成！** 訂單將自動同步至 Google 試算表

#### 5️⃣ 設定定時自動發信

1. 返回 Apps Script → 點擊 **觸發條件**（時鐘圖示）
2. 點擊 **+ 新增觸發條件**
3. 設定：
   - **功能**: `sendDailySummaryEmail`
   - **來源**: **時間驅動**
   - **類型**: **特定日期計時器**
   - **時段**: **中午 12 點到下午 1 點**
4. 點擊 **儲存**

> ✅ **完成！** 即使電腦關機，Google 雲端每天中午 12:00 也會準時寄送統計報表！

## 🔒 常見問題與安全性

### Q1: 維護端密碼安全嗎？

> 本系統採用 **純前端驗證**，適合內部辦公室、班級等可信賴環境使用。  
> ⚠️ **不建議** 存放高度敏感的商業機密或個人資料。

### Q2: 重複點餐會如何處理？

> 系統內建 **同座號防呆覆蓋機制**：
> - 同座號當天再次點餐時，系統會提示並將原訂單 **覆蓋**
> - 不會造成重複計數或重複收費

### Q3: 如何變更截止時間？

> 進入 **維護端** → **設定**，可調整每日點餐截止時間（預設 12:00）。

### Q4: AI 辨識不準確怎麼辦？

> - 確保菜單圖片清晰、無遮擋
> - 可於維護端手動編輯修正辨識結果
> - 或直接上傳符合格式的 CSV 檔案
